# tiny-wb 0.1.5

This release adds Apple Silicon and Intel macOS downloads alongside Linux and
Windows. The README now walks new users through a first scan, with screenshots
of the real application using clearly labelled simulated data.

## Downloads

Choose the archive for your computer, extract it, and run `tiny-wb` (or
`tiny-wb.exe` on Windows) from a terminal:

| Platform | Target |
| --- | --- |
| Linux x86-64 (glibc, system libudev required) | `x86_64-unknown-linux-gnu` |
| Windows x86-64 | `x86_64-pc-windows-gnu` |
| macOS Apple Silicon | `aarch64-apple-darwin` |
| macOS Intel | `x86_64-apple-darwin` |

Each target has a `.tgz` archive and a standalone executable. `SHA256SUMS`
covers all eight payload files.

macOS requires version 13.0 or newer. These are separate, unsigned and
unnotarized command-line executables, not universal binaries or `.app` bundles.
The release pipeline checks Mach-O architecture, deployment minimum, system
library paths, archive layout and checksums. Native macOS execution and USB
hardware behavior remain unverified by this Linux release workflow.

## Release workflow

All four targets now use `release.sh` and `rust_realease`. Apple builds use the
pinned cargo-zigbuild image; Linux and Windows use Cross. The obsolete standalone
macOS build script and its tests have been removed.

See the [README](https://proxy.dandaedre.com/gitea/idle-org/tiny-wb/src/tag/0.1.5/README.md)
for setup, your first scan, result controls and CSV export.
